# dsh-i18n-layout-fix

Bundle-плагин DeepSeek Harness, который убирает обрезание длинных переводов в
интерфейсе и добавляет исправленный русский язык.

## Что исправляет

- **Диалог обновления версии** (`HostReleasePrompt`, клиентский диалог Web UI):
  длинная русская подпись «Перезагрузите, чтобы загрузить новую версию» больше
  не обрезается в кнопке высотой 36 px. Кнопки переносятся, растут по высоте и
  остаются внутри диалога.
- **Навигация настроек**: подписи разделов («Встроенные плагины», «Настройки
  агента») переносятся вместо `ellipsis`.
- **Формы и вкладки в диалогах**: снимаются искусственные минимумы ширины,
  подписи вкладок переносятся.
- **Высокие диалоги**: у контентной колонки появляется владелец прокрутки, поэтому
  длинный текст не обрезается на коротком экране и при масштабировании.

Стили применяются глобально к основному документу (включая порталы), но
ограничены перечисленными компонентами: никаких универсальных `button`,
подстрок CSS Modules, селекторов по переводу или `MutationObserver`.

## Ограничения

- **Диалог обновления Desktop-оболочки** открывается Electron-оболочкой
  (`dshDesktop.updates.open()`), у него нет клиентского DOM и официальной точки
  расширения в установленной версии. Плагин исправляет клиентский диалог
  `HostReleasePrompt`; критерий по диалогу обновления выполнен частично.
- Официальный `LocaleRuntime` не допускает второго владельца пары
  `(namespace, locale)`, поэтому обычный русский не переопределяется на месте:
  исправления доступны только как отдельный язык `ru-x-dshfix`.

## Исправленный русский

Официальный `LocaleRuntime` не позволяет повторно зарегистрировать пару
`(namespace, locale)`, поэтому плагин добавляет отдельный выбираемый язык
**«Русский (исправленный)»** (`ru-x-dshfix`, fallback `ru`). В нём исправлены
только доказуемо ошибочные подписи встроенного namespace `settings`; обычный
русский не заменяется.

Включить можно двумя способами:

- **Настройки → Общие → Адаптивность и локализация → «Включить исправленный
  русский»**;
- штатная строка **Язык** → «Русский (исправленный)».

Автоматически язык не выбирается. Подробности и таблица исправлений —
в [docs/COMPATIBILITY.md](./docs/COMPATIBILITY.md).

## Установка

```bash
pnpm --filter dsh-i18n-layout-fix run build
```

Затем установите каталог `packages/dsh-i18n-layout-fix` как bundle:

- Web UI: **Плагины → Добавить плагин → локальный каталог**;
- агент с `plugin_manager`: `action: "install_bundle"`, `target` — абсолютный
  путь к `packages/dsh-i18n-layout-fix`.

После установки откройте **Настройки → Общие**.

## Отключение

Отключите bundle в **Плагинах**. Плагин не меняет исходники ядра, профиль,
preload или настройки темы: при выгрузке удаляются его `<style>`, словари, язык
`ru-x-dshfix` и строка настроек. Остаточных изменений в UI нет.

## Разработка

```bash
pnpm --filter dsh-i18n-layout-fix run typecheck
pnpm --filter dsh-i18n-layout-fix run test:unit   # vitest
pnpm --filter dsh-i18n-layout-fix run test:ui     # Playwright, нужен Chromium
```

E2E-тесты поднимают изолированный Host через `DSH_HOME` внутри `.artifacts/` и
сами устанавливают плагин через `--patch`; `DSH_TEST_URL` позволяет указать уже
запущенный Host (токен не печатается в отчётах).

Структура:

```
src/index.ts              Host-половина (пустая: поведение в Client)
src/client/index.ts       регистрация ресурсов, Cordis lifecycle
src/client/layout.css     ограниченный CSS-контракт
src/client/styles.ts      один <style> + disposer
src/client/locale.ts      словари и язык ru-x-dshfix
src/client/StatusRow.tsx  строка в «Настройки → Общие»
tests/ui/                 Playwright: layout, update-dialog, lifecycle, regressions
```
